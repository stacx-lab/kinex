Call a named device with action (default read) and args. Its profile declares operations, units and parameters. Prefer servo for arm goals and run_policy for synchronized action chunks. Servo waits its planned duration by default. Set block=false to return immediately. Verify arrival with measured feedback.
Load an inactive device before use. load/unload accept no arguments; status inspects readiness without starting services. Calls enforce device permissions. Python tools cannot load or unload devices.
Results contain data and/or a file path. Camera reads accept output="file", "base64", or "array". Direct reads default to base64 and attach the RGB image with camera identity and timestamp in every mode; no file-opening call is needed. Inside Python tools, reads default to arrays; base64 returns encoded images and file returns saved paths. Resolve named device:frame references with relative_pose. World read returns time_s and optional budget {used_s,max_s}: episode time consumed and allowed in seconds, with max_s null for no cap. Budget is driver-reported information, not enforced by Kinex. world.wait(duration_s) waits on the driver clock and returns time_s and waited_s for that wait, without a budget. Actuator writes take duration_s and return immediately; use world.wait to pace control.
verbose defaults to true; false omits empty optional feedback while preserving faults, timestamps and unknown fields. compact selects single-line JSON.

Use devices with calls: [{deviceID, action?, args?}] for concurrent device calls.
