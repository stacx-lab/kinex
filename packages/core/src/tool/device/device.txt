Call one device by name: action (default read) and args. The device inventory and injected type conventions describe available behavior; read its profile for parameters and model operation schemas.
write/stop and custom actuated verbs require permission. load/unload activate or release any device through device_act permission; they accept no arguments. Load before reading or commanding an inactive device. status reports readiness without starting services. A write requires positive for_s and runs the goal within that budget in the device's own clock, reporting elapsed_s, reached and the resulting state; prefer controller tools such as move_to, drive and track over stepping writes by hand. Use kinex.devices() for concurrent calls, including mixed reads and writes.
Results are inline data and/or a file path. Camera images are shown directly; depth files are numerical data interpreted using the profile. Model inputs/defaults/outputs are validated against declared operations. World has no driver; its load/unload/status are no-ops apart from the inventory activation flag. Named frames are profile intrinsics; resolve device:frame references with relative_pose.
