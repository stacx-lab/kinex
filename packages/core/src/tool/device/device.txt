Call one operation of a device: deviceID, action and args.
action is an operation its profile declares: an output topic returns its next message (an image as an attachment), a service takes args as its request, an input topic takes args as its message. A goal, an action operation, runs only in exec.
load, unload and status take no args: load starts the device and waits until it is ready, unload releases it, status reports readiness without starting anything. stop runs the device's declared stop and cancels the programs that commanded it.
Prefer exec for streams and for several operations in a row.
