Persist profile facts in the workspace. Invalid updates are not saved; errors name the fields and the device guide to consult.
- robot: partial workspace manifest; identity needs id, name and kind (arm, mobile, quadruped, humanoid or other) on first write.
- device: partial profile with its name; type and description on first write. Follow setup-device and the device guide for its fields.

Patches deep-merge; arrays replace wholesale. To replace a top-level section, supply it whole and list it in replace; null there removes an optional section. Changing a device's type or rgb layout replaces its profile, so supply all of it. Unknown facts stay ???; null means absent or inapplicable, never unknown. Set source to where the data came from.

Activation is not a profile fact: new devices are unloaded, and loading uses the device tool (action="load") or /load. Unload a device before changing its type, runtime or operations.
