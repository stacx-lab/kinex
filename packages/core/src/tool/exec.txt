Run a Python program in the workspace's Kinex Python, given as python source or a saved file. Python cannot load or unload devices or control recording.
A program is a complete script that ends with finish:
  import asyncio
  from kinex import args, device, finish, lib, world

  async def main():
      arm = device("arm")
      await arm.topic("joint_target").publish(args()["trajectory"])
      await world.wait_all([1.0])
      state = await arm.topic("joint_state").next()
      finish({"positions": state.position})

  asyncio.run(main())
finish(result=None, file=None) is the only way to return. result is JSON data: messages, arrays, poses and times are converted. file attaches the images you must see: an image message or path, or a list of them. Printed text is returned too; keep it short.
runtime discovers devices without starting them: runtime.devices(), runtime.operations(name), runtime.describe("device.operation"). Use the names these give, never guessed ones.
device(name) reaches a loaded device by the operations its profile declares:
- topic(op): await .next() is an output's next message, .latest the last received; await .publish(message) commands an input.
- service(op)(**fields): await it for the response; a rejection raises kinex.OperationError.
- action(op)(**fields): sends a goal and returns it at once. Wait for it on world; then goal.status and goal.result say how it ended, and await goal returns the result or raises if it failed. await goal.cancel() ends it.
A pose field takes kinex.pose(value) or [x, y, z, qx, qy, qz, qw]; a time field takes seconds.
world is time, and time passes for a program only in its waits. await world.now() is (time_s, used_s, max_s): world time and the time budget in seconds, None without one. await world.wait_all(entries) waits until every entry is over and await world.wait_any(entries) until one is; an entry is a goal or seconds from now. Both return whether each entry was over; timeout=seconds ends the wait and cancels the goals still executing. async for now in world.rate(hz) ticks. Never wait with asyncio.sleep, time.sleep or by awaiting an unfinished goal. Send the goals of different devices, then wait once for all. Sending is not arrival: wait, then read fresh feedback. Bound every loop.
lib holds reusable functions: find them with the lib tool, call lib.module.function(...).
await kinex.subagent(instruction, show={"wrist": image}) returns a model's judgment as text; it sees only what is shown and has no tools, so state the reply's form and check it.
Failure, timeout or cancellation stops every device the program commanded; success leaves motion running.
