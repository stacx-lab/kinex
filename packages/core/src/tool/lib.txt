Browse kinex.lib, the library of Python programs that exec composes and runs by name, one level at a time. Read-only; it never starts Python or a device.
- No path: the library's modules, each with its origin (workspace, global or builtin) and a one-line summary.
- A module path, such as images: its docstring, its submodules and the names of the public functions it defines.
- A function path, such as images.camera_frame: its signature as written, its docstring, and the source file and line to read for the implementation.
Modules nest to any depth; extend the path one name at a time. A workspace module replaces a builtin of the same name. problems lists files that cannot be imported or names that collide.
Inside exec, lib is preset: await lib.images.camera_frame("camera"). Run one function directly with exec's program input.
