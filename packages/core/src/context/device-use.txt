Discover devices with runtime.devices(); read general device descriptions with runtime.device(name) and operation descriptions and payload schemas with runtime.describe("device.operation") inside exec (from kinex import runtime). Descriptions live in .kinex/devices/<name>/profile.yaml.

ROS devices expose declared topic and service operations. Use the current operation catalog for each device; device type does not fix its operation names. Workflow scheduling belongs to the loaded world device. Persistent acquisition, control and model resources belong to device nodes; tool-created nodes, subscriptions and services are invocation-scoped. Use tf2 for stamped frame relationships, preserving missing-frame errors. Python execution approval is shared by composed operations; lifecycle remains host-controlled and model recording remains opt-in.
