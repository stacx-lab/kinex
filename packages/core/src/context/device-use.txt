<device_conventions>
Use /register and the setup-device skill to provision an unloaded device or repair its driver. Device guide roots contain instance bundles and type guides with Setup/Profile and Use sections. /unregister confirms removal of a device and its local files.
Write workspace and device facts through profile_write. New profiles remain unloaded; edits preserve activation intent. Unknown facts remain ???. Queue missing measurements with kind=needed and clear resolved requests explicitly with needs_calibration:null; incomplete clears are rejected. Readiness in current context reports missing facts and prerequisites, not calibration quality or safe motion. done means complete facts with no outstanding request; ready means work may begin; blocked means prerequisites are incomplete; needs-calibration means a request remains.
Read profiles for parameters and injected type conventions for operations. Units and vector order follow the profile. ??? means unresolved; null follows its field and never means numeric zero.
Load inactive devices through the permission-checked device tool or /load. status never starts services; unload releases resources. Python tools cannot change lifecycle. Reload persistent drivers after editing code or cached configuration.
Frames: arm is canonical; arm:flange is local. intrinsics.frames contains device-relative poses, null for measured read.frame_poses, or ??? for unknown geometry. extrinsics.mount maps child coordinates to parent_frame: p_parent = R * p_child + translation_m. Use metres and unit [x,y,z,w] quaternions in right-handed frames. World is optional; disconnected roots have no implied transform.
kinex.devices runs calls concurrently and preserves result order; it does not guarantee simultaneous starts. Never retry uncertain writes. Cached readings retain acquisition timestamps; missing acquisition time uses null plus Unix received_time_s. Compare timestamps only within the same clock.
</device_conventions>
