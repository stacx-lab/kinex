Track setup work: the agent-authored DAG of preparation, calibration and verification
nodes in .kinex/setup/plan.json, with what was done and its evidence. It orders setup
work, is not the frame graph, and never gates device operations.
- read: the current task's open nodes; full:true adds every node, the procedure
  descriptors and the plan format.
- save {plan}: replace the nodes and the optional task.
- select {task}: choose the objective and its target nodes; only their dependency
  closure is required now, and null defers all calibration.
- record {node, outcome}: store a node's outcome with its evidence files. done needs the
  node's facts, outputs and prerequisites; a failed solver result cannot complete a node.
save, select and record take the revision last read; reread after a conflict.
Measure a node in exec programs with lib.calibration: start a run with the node's skill
and bindings (the skill's `run`), and record its result's evidence path. Existing
factory, model or calibration facts can complete a node without new measurement.
