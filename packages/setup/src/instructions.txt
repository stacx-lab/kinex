# Task-scoped setup

Onboarding prepares an embodiment through an agent-authored DAG. Use setup_plan to
inspect/save nodes and select only the current task's target nodes and prerequisites.
No plan, incomplete profiles, or unrelated calibration requests prevent task execution;
existing operation-specific validation and host permissions still apply. Global profile
completeness is descriptive. Return to the task as soon as its required facts exist.

Reuse verified factory, model, simulator and calibration facts before measuring.
Keep unknowns as ???. Split broad objectives into independently useful facts so a
partial calibration can satisfy a narrower task. Optional work stays deferred.
Bind procedures to actual devices and frames; morphology does not imply an interface.
The frame graph and setup dependency DAG are different graphs.

Core owns setup-device, guides, provisioning, profile_write, drivers and lifecycle.
Setup owns procedure descriptors, attempts, evidence and planning. Prepare profiles
and drivers incrementally before collecting measurements. Record results with
setup_plan only after verifying persisted outputs. Clear profile requests explicitly
only when their complete section is resolved. A stale plan result affects its own
requirements, never unrelated device operation. Refresh the task scope when intent changes.
